# Kingdom 818

Recruitment site for Kingdom 818 in Kingshot: five alliances under one banner, with a sign-up form for future Server Transfers.

Single file site: everything is in `index.html`. To update content, edit the `CONFIG` block at the top of the script (alliances, event times, Discord invite, next transfer date, form endpoint).

Fan-made. Not affiliated with or endorsed by Century Games or Kingshot.
